# Night Audit: the website

The website for the hotel social-reports prototype. It's a React single-page app built with Vite.

- Every number, check and permission comes from the Python server in the parent folder. All calls to it go
  through `src/lib/audit/api.ts`, and the response shapes are in `src/lib/audit/types.ts`.
- The website never works out report numbers or decides who may see what. If the server refuses a request (403),
  the page shows the "Access denied" stamp.
- `npm run build` writes `dist/`, which `python3 app.py` serves at `/`.
- `npm run dev` runs on http://localhost:5173 and passes `/api` calls to `http://127.0.0.1:8000`, so start
  `python3 app.py` first.
- `npm test` runs quick page tests.
- `src/routeTree.gen.ts` is generated by the build, so don't edit it by hand.
